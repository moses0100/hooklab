# ทำต่อทีละส่วน

## รอบแรก — เสร็จแล้ว

- รับ webhook แบบ structured และเก็บใน SQLite
- ประวัติ 200 รายการล่าสุด, body/headers/query, ค้นหา method/ID
- ปิดบังฟิลด์ที่รู้จักก่อนบันทึก พร้อมทดสอบ HTTP และ restart

## รอบส่งออก JSON — เสร็จแล้ว

- ปุ่มดาวน์โหลดในรายละเอียด request ที่เลือก
- Endpoint ส่งไฟล์ JSON จากข้อมูลที่ปิดบังแล้ว พร้อมชื่อไฟล์จาก ID/เวลา
- ทดสอบเนื้อหาไฟล์, การปิดบังค่าลับ และกรณีไม่พบรายการ

## รอบลบรายการที่เลือก — เสร็จแล้ว

- Endpoint `DELETE /api/requests/:id` ลบรายการที่เลือกและคืน 404 หากถูกลบไปแล้ว
- ปุ่มลบรายการพร้อมหน้าต่างยืนยัน และแจ้งสถานะเมื่อรายการที่เปิดอยู่ถูกลบจากอีกแท็บ
- ทดสอบการลบ, การลบซ้ำ (404) และการบล็อกคำขอข้าม origin (403)

## รอบถัดไป — ขอบเขตแนะนำ

เลือก response status สำหรับจำลอง webhook failure

## หลังจากนั้น

- รองรับหลาย inbox เมื่อมีเหตุผลใช้งานจริง
- ตรวจการเชื่อมต่อจาก n8n Docker แยกจาก localhost บนเครื่อง

Public hosting, authentication และ HTTP replay ต้องออกแบบเพิ่มก่อนทำ อย่าเปิด `0.0.0.0` หรือส่ง request ซ้ำไปบริการจริงจากรุ่นทดลองนี้
