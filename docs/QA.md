# ตรวจรุ่นแรก — 4 พฤศจิกายน 2026

ทดสอบบน Windows, Node.js 24.14.1 ผ่าน `npm run check` และ `npm test` ทั้ง 8 ข้อ:

- รับ JSON และปิดบังฟิลด์ซ้อน, header และ query ก่อนบันทึก
- form-urlencoded เก็บหลายค่าชื่อเดียวกันและปิดบัง password
- JSON เสีย, body ที่ไม่รองรับ และ body เกิน 256 KiB ไม่เพิ่มประวัติ
- จำกัดรายการล่าสุดและไม่อ้างถึง ID ที่ไม่มีอยู่หรือเกิน safe integer
- ปฏิเสธ Origin และ Host ที่ไม่ตรง local app
- restart แล้ว URL inbox และข้อมูลคงเดิม; ตรวจไฟล์ SQLite/WAL/SHM ว่าไม่มี secret sentinel
- หน้าเว็บและ assets โหลดได้ โดยไม่เปิดไฟล์ฐานข้อมูลหรือ source ผ่าน static route
- JSON ลึกเกิน 40 ชั้นถูกปฏิเสธก่อนบันทึก

ตรวจผ่านเบราว์เซอร์จริง:

- เริ่มจาก inbox ว่าง ไม่สร้างประวัติเอง
- ปุ่มส่งตัวอย่างทำ HTTP POST จริง แสดง request ใหม่และ body
- แท็บ Headers แสดง `x-api-key` เป็น `[REDACTED]`; Query ของตัวอย่างเป็น `{}`
- ค้นหา DELETE ที่ไม่มีอยู่แล้วแสดงข้อความไม่พบ เคลียร์ช่องแล้วรายการเดิมกลับมา
- ที่ viewport 390 × 844 ส่วนแสดงข้อมูลเรียงเป็นคอลัมน์เดียวและไม่มีการล้นขอบแนวนอน
- ไม่พบ console error ระหว่างตรวจ
